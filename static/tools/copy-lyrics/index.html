Copy lyrics for Codex

A private, one-action browser helper. It copies the selected text—or, when nothing is selected, the page’s most likely lyrics block. Nothing is uploaded or sent anywhere.

Copy lyrics for Codex

Desktop

  1. Drag Copy lyrics for Codex to your bookmarks bar.
  2. Open a lyrics page and click the bookmark. If the page is noisy, select just the lyrics first.
  3. Paste into Codex.

Android Chrome

  1. Bookmark any page and rename it Copy lyrics for Codex.
  2. Tap Copy bookmarklet code, edit that bookmark, and replace its URL with the copied code.
  3. On a lyrics page, type the bookmark’s name in the address bar and select it.
