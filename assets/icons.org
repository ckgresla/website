#+date: 2026-07-10

Edit freely — Claude keeps this in sync, and the website reads it directly
(=just icons= copies it to =assets/icons.org=, and the doodle icons page
renders the unchecked items as its "Most Wanted" list).

Keep each =- [ ]= line self-contained: the text after the em-dash is shown
publicly. Working notes go on plain lines beneath, which the site ignores.

* Drawn
- [X] bulb — family of ten
  Pack and exact bodies, each with base / wire / squiggle / lit variants.
- [X] music — nine atoms
  Treble and bass clefs, sharp, flat, note ±shadow, whole-note,
  notes-beamed ±shadow. The composed note-group pair was retired and now
  lives inline on the progetti card.
- [X] clock — classical, digital
  A classical clock at five to four and a digital one reading 11:11, each with a
  no-shadow variant; both wear the clock's card on the projects page (Sept 2026).
- [X] weather — twelve skies: clear, clear night, partly cloudy, cloudy, overcast, fog, drizzle, rain, heavy rain, snow, sleet, thunder; and sunrise, sunset
  Drawn for the clock's weather item (Sept 2026): the pack's cloud lifted with
  the weather beneath it, a wobbly sun, a crescent, the chunky bolt small and
  solid for thunder. Each with a no-shadow variant, which is what the clock
  uses — they float.
- [X] ckg spirit — blob, loop, water, air, fire (and candle), earth
  The site's spirit as one mark drawn seven ways, each with a no-shadow
  variant: the two general pieces, then the four elements as eight particles
  each, and fire twice — aggressive, and calm as a candle. Baked from the
  Eight Pebbles page in website/design/logo, which is where they move.
- [X] kangaroo
  The Switcharoo project's hop, folded into the generator.
- [X] calendar — a day picked, and plain, each with a no-shadow variant
  Drawn for the site's /chat/ booking page.
